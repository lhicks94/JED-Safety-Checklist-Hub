# JE Dunn Safety Checklist Hub - Microsoft Backend Package

This package replaces the Firebase backend connector with a Microsoft-compatible connector.

## Files

- `microsoft-backend.js`  
  Upload this to the same GitHub repository as `index.html`.

- `power-automate-request-schema.json`  
  Use this schema in Power Automate when configuring an HTTP request trigger.

- `sharepoint-list-columns.md`  
  Suggested Microsoft List / SharePoint List columns for storing checklist submissions.

- `MICROSOFT_BACKEND_README.md`  
  This file.

## How this architecture works

```text
GitHub Pages public checklist hub
        ↓
Worker submits checklist
        ↓
microsoft-backend.js posts JSON to Power Automate
        ↓
Power Automate creates Microsoft List / SharePoint record
        ↓
Power Automate saves photos to SharePoint document library
        ↓
Future admin dashboard reads from Microsoft List / SharePoint
```

## Required change to index.html

At the bottom of `index.html`, right before `</body>`, add:

```html
<script src="microsoft-backend.js"></script>
```

## Required change to microsoft-backend.js

Replace this placeholder:

```js
const POWER_AUTOMATE_SUBMISSION_URL = "PASTE_POWER_AUTOMATE_HTTP_POST_URL_HERE";
```

with the HTTP POST URL generated by your Power Automate flow.

## Microsoft 365 backend target

Recommended Microsoft storage:

1. Microsoft List or SharePoint List for checklist submission metadata and response data.
2. SharePoint document library for photo files and future generated PDFs.
3. Future admin dashboard web page that reads the list and groups submissions by company.

## Important notes

- Do not place passwords, client secrets, or confidential credentials into GitHub.
- The Power Automate HTTP URL should be treated as sensitive because it receives public submissions.
- This package does not build the dashboard yet. It only replaces Firebase with a Microsoft-compatible submission connector.
